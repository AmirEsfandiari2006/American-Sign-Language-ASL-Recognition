# American Sign Language (ASL) Recognition

A deep learning project to classify American Sign Language (ASL) hand gestures from images using TensorFlow/Keras.

## Project Overview
- **Goal:** Real-time / image-based recognition of ASL alphabet signs.
- **Model:** Convolutional Neural Network (CNN) saved as `best_asl_model.h5`.
- **Framework:** Python, TensorFlow, Keras, OpenCV.
